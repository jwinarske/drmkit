# drmkit-fmt

Format-modifier and hardware-compression support for drmkit's plane
allocator: `IN_FORMATS` tables, modifier classification, and the bandwidth
cost placement scoring weighs.

Part of [drmkit](https://github.com/jwinarske/drmkit), a Rust port of
[drm-cxx](https://github.com/jwinarske/drm-cxx). API documentation is on
[docs.rs](https://docs.rs/drmkit-fmt).
